## 📦 SA-sheeesh — Simple Online Ordering System

SA-sheeesh is a lightweight, PHP-based online ordering system designed for small businesses or school projects.
It includes user authentication, product management, shopping cart functionality, and an admin dashboard for handling orders.

---

## 🚀 Features
## 👤 User Features

Create an account / login

Browse available products

Add items to cart

Update item quantities

Checkout and confirm orders

View personal settings

---

## 🛒 Shopping Cart

Add products

Remove items

Increase or decrease quantities

Automatic total calculation

---

## 🛠️ Admin Features

Admin dashboard

Add new products

Manage orders

View customer information
